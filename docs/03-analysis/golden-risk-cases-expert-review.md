# VESTRA 전세 위험도 분석 — 전문가 검증 사례집

> 목적: VESTRA의 등기부 기반 위험도 분석 엔진이 **현실에서 세입자에게 실제로 위험한 물건을 정확히 판정하는지**를 부동산 전문가(변호사·법무사·공인중개사)께 검증받기 위한 자료입니다.
> 작성일 2026-10-22 · 엔진 버전 `risk-v3-2026-10` · 사례 15건
> 검증 대상: `__tests__/golden-risk-cases.test.ts` (매 배포 CI 자동 검증)

---

## 1. 전문가께 드리는 요청

각 사례는 **합성 등기부**(현실의 전형적 상황을 재현)에 대해 VESTRA 엔진이 내린 판정입니다. 각 사례마다:

1. **엔진 판정(등급·점수·감지한 위험요인)**이 **현실의 위험도와 일치하는지** 판단해 주십시오.
2. **동의/수정**에 체크하고, 수정이면 **올바른 등급과 사유**를 적어 주십시오.
3. 특히 **"위험한데 안전으로 판정"(중대 위험 누락)** 또는 **"안전한데 과도하게 위험으로 판정"(과잉 경고)** 이 있으면 반드시 표시해 주십시오.

> ⚠️ 이 판정은 **등기부 데이터만으로 산출**됩니다. 시세·시장 전망·임대인 신용·실제 점유 상태 등 등기부 밖 정보는 포함하지 않습니다(불확실성은 '정보 미확인'으로 반영).

## 2. 등급 기준

| 등급 | 점수 | 의미 |
|---|---|---|
| **A** | 85~100 | 안전 |
| **B** | 70~84 | 양호 |
| **C** | 50~69 | 주의 |
| **D** | 30~49 | 위험 |
| **F** | 0~29 | 매우 위험 |

판정 방식: 기본 100점에서 위험요인별 감점을 누적. 선순위 채권·보증금 합이 시세를 넘으면 결정적 감점(깡통전세). 압류·경매·신탁·가등기·임차권등기 등은 권리 안정성 위협으로 감점.

## 3. 사례별 판정 (전문가 검토란 포함)

### 공통 가정: 시세 8.5억 (별도 표기 시 예외)

**G-001 · 선순위 채권 과다 + 가압류**
- 등기부: 선순위 근저당·전세권 합산이 시세 대비 과다, 갑구에 가압류(말소 전)
- 입력: 보증금 5.5억
- **엔진 판정: F (매우위험) / 0점** — 감지: 선순위 채권 과다, 가압류, 소유권 빈번 이전
- 판정 근거: 선순위 채권이 시세를 초과하고 가압류가 걸려 경매 시 보증금 회수가 어려움
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-002 · 깨끗한 등기 (근저당 시세의 18%)**
- 등기부: 소유권 이전 1회, 근저당 1.5억 소액, 압류·경매 없음
- 입력: 보증금 3억
- **엔진 판정: A (안전) / 100점** — 위험요인 없음
- 판정 근거: 선순위 부담이 적고 권리 하자 없음 → 안전
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-003 · 깡통전세 (선순위 근저당 시세의 85%)**
- 등기부: 선순위 근저당 7.2억 (시세 8.5억의 85%)
- 입력: 보증금 5.5억
- **엔진 판정: F (매우위험) / 29점** — 감지: 선순위 채권 과다
- 판정 근거: 선순위 근저당이 보증금보다 앞서고 합산이 시세 초과 → 보증금 회수 위험
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-004 · 압류 + 임의경매개시결정**
- 등기부: 활성 압류 + 임의경매개시결정 + 근저당 6억
- 입력: 보증금 4억
- **엔진 판정: F (매우위험) / 0점** — 감지: 압류, 경매개시, 복합위험 가중, 선순위 과다
- 판정 근거: 경매 진행 중 → 보증금 회수 치명적 위험
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-005 · 다중 근저당 + 소유권 6개월 내 3회 이전**
- 등기부: 근저당 2건 + 소유권이 6개월 내 3회 이전(사기 의심 시계열)
- 입력: 보증금 4억
- **엔진 판정: F (매우위험) / 12점** — 감지: 선순위 과다, 소유권 빈번 이전, 시계열 이상
- 판정 근거: 명의신탁·깡통전세 사기의 전형적 패턴
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-006 · 말소된 가압류 + 근저당 소액**
- 등기부: 과거 가압류가 **해제(말소)** + 근저당 1.5억 소액
- 입력: 보증금 3억
- **엔진 판정: A (안전) / 100점** — 위험요인 없음 (말소된 가압류는 현행 위험으로 보지 않음)
- 판정 근거: 말소된 권리는 현재 위험이 아님 → 안전 (과잉 경고 방지)
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-007 · 시세·보증금 미확인**
- 등기부: G-002와 동일(깨끗)하나 **시세·보증금 정보 없음**
- 입력: 시세 미입력 / 보증금 미입력
- **엔진 판정: B (양호) / 80점** — 감지: 정보 미확인(선순위 부담 확정 불가)
- 판정 근거: 등기는 깨끗하나 시세를 모르면 '안전(A)' 단정 불가 → 보수적으로 B + 불확실성 표시
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-008 · 본인 전세권 (세입자 본인 전세권 지정)**
- 등기부: 을구의 유일한 권리가 세입자 본인의 전세권 5억
- 입력: 보증금 5억, 본인 전세권 지정(순위1, 정민수)
- **엔진 판정: A (안전) / 100점** — 본인 전세권은 선순위 위험에서 제외
- 판정 근거: 본인 보증금(전세권)을 타인 선순위 위험으로 계산하면 과잉 경고 → 제외
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-009 · 신탁등기 (수탁자=신탁회사가 소유자)**
- 등기부: 소유권이 신탁회사(수탁자)에게 이전된 신탁등기 + 근저당 2억
- 입력: 보증금 4억
- **엔진 판정: D (위험) / 40점** — 감지: 신탁, 선순위 상당, 소유권 빈번 이전
- 판정 근거: 신탁 물건은 수탁자 동의 없이 임대 제한 → 계약 효력 불안정
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-010 · 소유권이전청구권 가등기**
- 등기부: 소유권이전청구권 가등기 + 근저당 2억
- 입력: 보증금 4억
- **엔진 판정: C (주의) / 60점** — 감지: 가등기, 선순위 상당
- 판정 근거: 가등기가 본등기로 전환되면 소유권 이전 → 임차인 대항력 상실 위험
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________
  - 참고: 엔진은 '주의(C)'로 감지하나, 가등기의 실제 위험도가 더 높다고 보시면 지적해 주십시오.

**G-011 · 선순위 근저당 6.7억 + 보증금 5억 (합산 시세 초과)**
- 등기부: 선순위 근저당 6.7억 (시세의 79%)

- **엔진 판정: F (매우위험) / 29점** — 감지: 선순위 채권 과다
- 판정 근거: 선순위+보증금 합이 시세를 크게 초과 → 회수 불가능에 가까움
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-012 · 주택임차권등기 (전 세입자 보증금 미반환 이력)**
- 등기부: 임차권등기명령에 의한 주택임차권 + 근저당 3억
- 입력: 보증금 4억
- **엔진 판정: D (위험) / 35점** — 감지: 임차권등기, 선순위 상당
- 판정 근거: 임차권등기명령 = 전 세입자가 보증금을 못 받아 법원이 등기한 것 → 임대인 반환 능력 문제 신호
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

**G-013 · 처분금지가처분 (소유권 분쟁 중)**

- 입력: 보증금 4억

- 판정 근거: 소유권 분쟁 진행 중 → 소유권 불안정, 계약 효력 위태
- **전문가 검토**: ☐ 동의  ☐ 수정 → 올바른 등급 (___) / 사유: ________________

## 4. 투명성 — 이 사례집 작성 중 자체 발견·수정한 결함 3건

검증 체계 구축 과정에서 엔진의 실제 결함 3건을 발견해 수정했습니다(전문가 판단의 참고):

1. **전세권자 식별 오류**: 전세권의 '전세권자(개인)' 이름을 등기목적("전세권설정")으로 잘못 읽어, 세입자 본인 전세권 제외가 작동하지 않던 문제 → 세입자 본인 보증금을 과잉 경고하던 것을 수정.
2. **신탁 미감지**: 신탁등기(소유권이전+수탁자)를 등기목적만 보고 놓쳐 위험을 과소평가하던 것 → 수탁자(신탁회사) 식별로 수정.
3. **가등기 미감지**: "소유권이전청구권가등기"를 완전일치 검색이 놓쳐 '양호'로 오판하던 것 → 포함검사로 수정(위험 누락 해소).
