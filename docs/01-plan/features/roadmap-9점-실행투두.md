- **기본 축 = 일반 개인회원 단 하나.**
  - 정의: 본인이 들어갈/사는 전세·월세 집의 안전을 확인하려는 개인(공인중개사·임대사업자·기업 아님).

- **반복 수익 문제와 해법**: 전세계약은 저빈도(2년 1회) → 반복 사용이 구조적으로 약함(PDF E축 리스크).

## 5. 제품설계 세션 — R-1/R-2/C-1 (2026-10-22)

> 핵심고객=일반 개인회원 / 반복수익=감시 구독전환. 대장 결정: 전환시점=**권리분석 결과 직후**, 과금=**단건→구독 업셀**.

### R-1. 권리분석 결과 → 등기감시 구독 전환 (PDF 8/10)

**진단**: 권리분석 결과의 `MonitoringRegisterButton`은 무료회원이 누르면 `/api/monitoring` **403 → "재시도" 버튼 + 에러 툴팁**으로 끝남. **전환 기회를 에러로 소모 중.** (비로그인은 401 동일)

**설계**: 403/401 경로를 **"감시 업셀 모달"**로 전환.
- 헤드라인: "계약 후에도 이 집, 안전할까요? 등기 변동을 자동 감시하세요."
- **옵션 A — 단건**(가벼운 진입): 1건·1개월·1만원 (기존 `GUEST_SINGLE_MONITORING` 상품 재사용, 즉시 결제)
- **옵션 B — 구독**(지속·다건): PRO(5건)/PREMIUM(20건) 월구독 (`renewal/pricing`)
- 비로그인: 모달에서 로그인 유도 후 동일 분기
- 성공 후: 감시 상세로 연결 (한 집 동선 완결)

**완료기준(PDF)**: 권리분석 결과 → 감시 등록(단건/구독) **전환율을 실데이터로 측정**(이벤트 기록).

### R-2. 재방문 트리거 (생애주기 반복)

- **단건 만료 전 업셀**: 1개월 단건 감시 만료 7일 전 "구독 전환/연장" 알림 → 저빈도→반복 전환의 핵심.
- **갱신 시점 재소환**: 전세 2년 경과 시 체크리스트(A-1)·재분석 알림.
- **완료기준**: 만료·갱신 시점 재활성 경로 존재 + 발송 로그.

### C-1. 계약 전후 동선 end-to-end 점검

- 집 등록 → 위험 확인 → 계약서 확인 → 잔금 전 재확인 → 계약 후 감시 **연결 끊김 점검**.
- **완료기준**: 일반회원 1명이 도움 없이 전 단계 완주 관찰(PDF 평가축 B).
