## 1. Overview

### 1.1 Purpose

두 가지 기능을 통해 VESTRA의 **피해자 지원** 역량과 **공신력·신뢰도**를 강화한다.

1. **긴급대응 플로우(Alert Flow)**: 등기감시 위험 알림이 발생하는 순간, 사용자가 "지금 당장 무엇을 해야 하는가"를 즉시 파악할 수 있도록 구조화된 대응 가이드 팝업을 제공한다. 기존 전문가 연결 기능과 연계하여 법률 상담 → 공식 피해지원 포털 연결까지 원스톱으로 안내한다.

2. **데이터 출처 배지(Source Badge)**: 권리분석·전세분석·계약서분석·시세전망 등 모든 분석 결과 영역에 분석에 사용된 공공데이터 출처(대법원·국토교통부·공시지가 등)를 배지 형태로 명시한다. 데이터 근거를 투명하게 공개해 사용자 신뢰를 높인다.

### 1.2 Background

- VESTRA 레이더 비교 분석 결과, **피해자 지원 2/10, 공신력·신뢰도 5/10**으로 두 영역이 취약점으로 식별됨
- 피해자 지원: 기존 전문가 연결 기능은 사용자가 능동적으로 찾아야 하는 구조 → 위험 감지 시점에 즉각 노출 필요
- 공신력: 대법원·국토교통부 등 공신력 높은 공공데이터를 실제로 활용하고 있으나 사용자에게 노출되지 않음 → 투명성 확보 필요
- 전세사기피해지원 포털(정부 공식): 사후 구제 채널로 VESTRA와 경쟁이 아닌 보완 관계 → 연결 포인트로 활용 가능

### 1.3 Related Documents

- 등기감시: `app/(app)/registry/` 관련 파일, `lib/registry-parser.ts`
- 전문가 연결: `app/(app)/expert-connect/`
- 권리분석: `app/(app)/rights/`
- 전세분석: `app/(app)/jeonse/analysis/`

## 2. Scope

### 2.1 In Scope

**기능 1: 긴급대응 플로우**
- [x] 등기감시 위험 알림 발생 시 긴급대응 모달 자동 표시
- [x] 3단계 대응 순서도: 증거 확보 → 공식 신고 → 법적 조치
- [x] 전세사기피해지원 포털 직접 링크 버튼
- [x] 준비 서류 체크리스트 (계약서, 등기부등본, 임대인 신분증 사본 등)
- [x] 전문가 연결 페이지로 바로가기

**기능 2: 데이터 출처 배지**
- [x] 분석 결과 상단/하단에 출처 배지 컴포넌트 추가
- [x] 권리분석·전세분석·계약서분석·시세전망 페이지 적용
- [x] 배지 클릭 시 해당 공공데이터 출처 설명 툴팁

### 2.2 Out of Scope

- 전세사기피해지원 포털 API 직접 연동 (링크 연결만 제공)
- 피해 신고 자동화 (공식 채널 직접 연결만 제공)
- 정부 기관 MOU·인증 취득 (별도 영업/법무 사안)

## 4. UI/UX 설계 방향

### 4.1 긴급대응 모달

```
┌──────────────────────────────────────────────────────┐
│  ⚠️  등기 변동 감지 — 즉시 확인이 필요합니다           [X] │
├──────────────────────────────────────────────────────┤
│  변동 내용: [변동 내용 요약]                            │
│  감지 일시: 2026-07-27 08:15                           │
├──────────────────────────────────────────────────────┤
│  📋 지금 해야 할 일                                     │
│                                                      │
│  1단계  증거 확보                                       │
│         □ 등기부등본 출력 (오늘 즉시)                   │
│         □ 임대차계약서 사본 보관                        │
│         □ 임차인 대항력 확인 (확정일자·전입신고)         │
│                                                      │
│  2단계  공식 신고                                       │
│         □ 경찰서 신고 (사기죄 고소장 접수)              │
│         □ 전세사기피해지원위원회 피해 신청               │
│                                                      │
│  3단계  법적 조치                                       │
│         □ 임차권등기명령 신청 (법원)                    │
│         □ 배당요구 신청 (경매 개시 시)                  │
│                                                      │
├──────────────────────────────────────────────────────┤
│  [🏛️ 전세사기피해지원 포털 바로가기]  [👤 전문가 상담]   │
└──────────────────────────────────────────────────────┘
```

### 4.2 데이터 출처 배지

```
분석 결과 하단:
┌─────────────────────────────────────────────────────┐
│  📊 데이터 출처                                       │
│  [대법원 등기부] [국토교통부 실거래가] [공시지가(VWorld)] │
│  [건축물대장(공공데이터포털)]                           │
└─────────────────────────────────────────────────────┘
```

배지별 툴팁:
- **대법원 등기부**: "대법원 인터넷등기소 API를 통해 실시간 조회한 등기부등본 데이터"
- **국토교통부 실거래가**: "국토교통부 실거래가 공개시스템(MOLIT) 공식 데이터"
- **공시지가(VWorld)**: "국토교통부 VWorld NED API — 개별공시지가·공동주택공시가격"
- **건축물대장**: "공공데이터포털 건축물대장 API 공식 데이터"

## 5. Architecture Considerations

### 5.1 파일 구조

```
components/common/
  EmergencyResponseModal.tsx    # 긴급대응 모달 (새 컴포넌트)
  SourceBadge.tsx               # 데이터 출처 배지 (새 컴포넌트)

lib/
  emergency-checklist.ts        # 체크리스트 항목 상수
  source-badges.ts              # 출처 배지 데이터 상수

app/(app)/rights/
  page.tsx                      # SourceBadge 추가
app/(app)/jeonse/analysis/
  page.tsx                      # SourceBadge 추가
app/(app)/contract/
  page.tsx                      # SourceBadge 추가
app/(app)/prediction/
  page.tsx                      # SourceBadge 추가
```

### 5.2 긴급대응 모달 트리거 방식

- 등기감시 알림 목록(`registry` 관련)에서 위험 등급 알림 클릭 시 모달 표시
- `isEmergency` 플래그 기준: 근저당 추가 설정, 소유권 이전, 가압류·압류·경매 개시
- 모달 상태는 컴포넌트 로컬 state (전역 상태 불필요)

## 7. Risks and Mitigation

| Risk | Impact | Likelihood | Mitigation |
|------|--------|------------|------------|
| 전세사기피해지원 포털 URL 변경 | Low | Low | 상수 파일로 분리해 쉽게 수정 가능 |
| 등기감시 트리거 조건 불명확 | Medium | Medium | 모달 수동 트리거 버튼도 병행 제공 |
| 출처 배지가 분석 결과 UI 복잡도 증가 | Low | Medium | 배지 영역을 구분선으로 분리, 시각적 노이즈 최소화 |
